AI Core HMI

Artificial Intelligence at the Core of Industrial Automation

The first open-source HMI / SCADA platform with AI built into every layer — from anomaly detection and predictive alarms to natural-language data queries and AI-assisted project engineering. Built on .NET 10, OPC UA, Blazor, and Ollama. Deploy everything — including a local LLM — with a single Docker image.

🧠 AI to the Core

AI Core HMI doesn't bolt AI on as an afterthought — it's woven into the runtime engine, the engineering editor, and the operator interface. Choose between OpenAI, Google Gemini, or a fully offline local LLM via Ollama (bundled in the Docker image on port 11434).

🔍 Anomaly Detection & Predictive Alarms

A dedicated background service (AnomalyDetectionService) continuously analyses historical data for every monitored variable using Z-score statistical analysis and linear-trend prediction.

  • Configurable per-variable: enable anomaly detection, set Z-score thresholds, baseline window size
  • Automatic predictive alarms — the system forecasts when a variable will breach its High/Low limit and fires an alarm before it happens
  • Computes rolling mean, standard deviation, and predicted time-to-breach in minutes
  • Anomaly events are logged, surfaced in diagnostics, and routed through the notification service (Email, Telegram, WhatsApp, Alexa, IP Speakers)
  • Scales to 100K+ variables with batched analysis cycles

💬 Natural-Language Data Queries

Operators can ask plain-English questions about their process data and get instant AI-powered answers — no SQL, no dashboards, just conversation.

  • "What was the maximum temperature in AHU1 yesterday?"
  • "Show me the average pressure over the last 2 hours"
  • "Did any flow sensor spike this week?"

The NaturalLanguageQueryService automatically:

  • Identifies relevant logged variables by matching question keywords to tag paths
  • Parses natural time references ("yesterday", "last 3 hours", "this month")
  • Fetches historical data and computes statistics (min, max, avg, std dev, sum)
  • Builds a rich context prompt and sends it to the configured AI engine
  • Returns a concise, human-readable answer with variable names, values, and timestamps

Supports OpenAI (GPT-4o), Gemini, and Ollama (Mistral, Llama 3, etc.) — works fully offline with the bundled Ollama instance.

🤖 AI-Assisted Project Engineering

The web editor embeds a full AI assistant (AiService) that understands the OPC UA project model and can modify your configuration via natural-language instructions.

  • Multi-engine support — switch between OpenAI, Gemini, and Ollama from the editor UI
  • "Add 10 temperature variables with Modbus driver config" — the AI generates valid JSON and merges it into your project
  • PLC import intelligence — feed a Siemens TIA Portal XML export, KNX ETS CSV, or Modbus register map, and the AI parses it into fully-configured HMI variables with correct driver addresses, data types, and folder structures
  • Context-aware editing — the AI sees your current project JSON and a reference file simultaneously, producing accurate merges
  • Ollama training — scan your sample projects and PLC export files to build a local knowledge base that is prepended to every prompt, teaching the model your project conventions
  • Model management — list and switch between available Ollama models (Mistral, Llama 3, CodeGemma, etc.) directly in the editor

🏠 Embedded Ollama — Fully Offline AI

The all-in-one Docker image ships with Ollama on port 11434, giving you a local LLM that runs entirely on your hardware — no cloud, no API keys, no data leaving your network.

  • Default model: Mistral — fast, capable, runs on modest hardware
  • Swap to Llama 3, CodeGemma, Phi-3, or any Ollama-supported model with one setting change
  • Auto-detected via OLLAMA_HOST environment variable in containers
  • First request after container start loads the model into memory (30–90 s); subsequent requests are instant
  • Perfect for air-gapped industrial environments where cloud connectivity is unavailable or prohibited

📊 Statistical Intelligence

Beyond AI models, the platform embeds real-time statistical engines:

  • Variable Statistics — per-variable min, max, average, count tracked as live OPC UA sub-variables
  • Rolling baselines — anomaly detection maintains configurable sliding windows for mean and standard deviation
  • Trend extrapolation — linear regression on recent data points predicts future values and time-to-breach
  • Historical aggregation — the NL query engine computes on-the-fly statistics over any time range before feeding context to the LLM

🔔 AI-Driven Notifications

When anomaly detection or trend prediction triggers an alert, the notification pipeline delivers it across multiple channels simultaneously:

  • Email (SMTP with TLS)
  • Telegram Bot API
  • WhatsApp Cloud API
  • Amazon Alexa voice announcements
  • IP Speakers (Sonos / UPnP)

Each anomaly event includes the variable path, current value, Z-score, predicted time-to-breach, and a human-readable message.

🔮 Predictive Screen Navigation & Variable Pre-Connection

The runtime viewer learns operator navigation habits using a Markov-chain model (NavigationPredictorService) and predicts which screen the operator will open next.

  • Every screen navigation is recorded and the transition matrix is persisted per-project
  • The system predicts the most likely next screen with a confidence score
  • Variables needed by the predicted screen are pre-subscribed on the OPC UA connection (PreconnectVariables) — values are already flowing before the operator even clicks
  • Result: near-instant screen loads with live data appearing immediately, eliminating the typical "connecting…" delay
  • Configurable minimum confidence threshold and sample count before predictions activate

🖥️ Native Desktop Runtime — Windows & Linux

In addition to the browser-based Blazor apps, AI Core HMI ships native desktop executables powered by Photino.NET — a lightweight, cross-platform webview framework.

  • RuntimeViewer.Desktop — native runtime viewer for operators (Windows, Linux, macOS)
  • ServerEditorWeb.Desktop — native project editor for engineers
  • No browser needed — runs as a native window with full OS integration
  • Same Blazor UI, same AI features — natural-language queries, tag browser, alarm management all work natively
  • Built on .NET 10 — single dotnet publish produces a self-contained executable
  • Ideal for dedicated HMI terminals and kiosk-mode operator stations

Platform Features

🖥️ Blazor Web Editor

Full-featured project editor running in the browser. Design HMI screens with drag-and-drop widgets, configure variables, write scripts, and manage your entire project — no desktop install required.

🔗 OPC UA Server

Built-in OPC UA server exposes all project variables, alarms, and methods. Supports certificate management, Global Discovery Server (GDS) registration, and trust-list workflows.

🏭 Industrial Drivers

Connect to real hardware out of the box: Modbus, Siemens S7, EtherNet/IP, KNX, OPC UA Client, MQTT, Sparkplug B, REST, TCP, SQL, CSV, and a built-in Simulation driver.

🚨 Alarm System

Configure alarms per variable with activation notifications via Email, Telegram, WhatsApp, Alexa, and IP Speakers. Operators can acknowledge, confirm, shelve, and unshelve alarms at runtime.

🏷️ Runtime Tag Browser

Hierarchical tree view of the OPC UA address space with real-time search, live value polling, and inline write capability — directly in the RuntimeViewer.

💾 Backup & Restore

Automatic and scheduled project snapshots with retention management. One-click restore creates a safety backup before reverting, so you never lose work.

🔐 Security

PBKDF2-SHA256 password hashing, user groups with granular access levels, idle auto-logoff, password expiry, project-level password protection, and strong password policy enforcement.

🌍 Localization

Full multi-language support (EN, DE, IT, FR, JA, ZH) for the editor help system and runtime string tables.

🔐 Certificate Management

View, generate, and manage OPC UA PKI certificates. Register with a GDS, submit CSRs, pull signed certificates, and accept or reject certificates — all from a dedicated editor panel.

☁️ Cloud Bridge & Relay

Extend your on-premises HMI to the cloud with CloudBridge and CloudRelay services for remote monitoring and control.

Architecture Overview

Server

OPC UA server, alarm engine, anomaly detection, notification service, REST API, driver host. Ports 14840 (OPC UA), 14841 (diagnostics).

ServerEditorWeb

Blazor Server app for project editing with built-in AI assistant (OpenAI / Gemini / Ollama). Port 8080.

RuntimeViewer

Blazor WebAssembly runtime UI with alarm list, tag browser, NL query chat, diagnostics panel. Port 8088.

Ollama

Embedded local LLM server for fully offline AI. Runs Mistral by default, swappable to any model. Port 11434.

Drivers

13 industrial protocol drivers with a common Drivers.Abstractions interface.

Docker All-in-One

Single container image bundles Server + Editor + Viewer + PostgreSQL + Ollama for zero-config deployment.

🐳 Docker Quick Start

The fastest way to try AI Core HMI is the all-in-one Docker image. It bundles the OPC UA server, web editor, runtime viewer, PostgreSQL, and Ollama (local AI) into a single container.

Pull & Run (All-in-One)

# Pull the all-in-one image
docker pull ghcr.io/clodalone/hmi-allinone:latest

# Run with persistent volumes
docker run -d --name hmi \
  -p 14840:14840 \
  -p 14841:14841 \
  -p 8080:8080 \
  -p 8081:8081 \
  -p 8088:8088 \
  -p 5432:5432 \
  -p 11434:11434 \
  -v hmi-data:/data \
  -v hmi-pgdata:/var/lib/postgresql/data \
  hmi-allinone:latest

Individual Images

You can also run each component separately:

Build from Source

# Clone the repository
git clone https://github.com/ClodAlone/HMISolution.git
cd HMISolution

# Build the all-in-one image
dotnet build Server/Server.csproj -c Release -p:BuildDockerImage=true

# Run
docker run -d --name hmi \
  -p 14840:14840 -p 14841:14841 \
  -p 8080:8080 -p 8081:8081 -p 8088:8088 \
  -p 5432:5432 -p 11434:11434 \
  -v hmi-data:/data \
  -v hmi-pgdata:/var/lib/postgresql/data \
  hmi-allinone:latest
