HMI Solution

A modern, open-source HMI / SCADA platform built on .NET 10, OPC UA and Blazor. Design screens, connect PLCs, browse tags, manage alarms — all from your browser or desktop, and deploy with a single Docker image.

🐳 Get Docker Images ⭐ Star on GitHub

Platform Features

🖥️ Blazor Web Editor

Full-featured project editor running in the browser. Design HMI screens with drag-and-drop widgets, configure variables, write scripts, and manage your entire project — no desktop install required.

🔗 OPC UA Server

Built-in OPC UA server exposes all project variables, alarms, and methods. Supports certificate management, Global Discovery Server (GDS) registration, and trust-list workflows.

🏭 Industrial Drivers

Connect to real hardware out of the box: Modbus, Siemens S7, EtherNet/IP, KNX, OPC UA Client, MQTT, Sparkplug B, REST, TCP, SQL, CSV, and a built-in Simulation driver.

🚨 Alarm System

Configure alarms per variable with activation notifications via Email, Telegram, WhatsApp, Alexa, and IP Speakers. Operators can acknowledge, confirm, shelve, and unshelve alarms at runtime.

🏷️ Runtime Tag Browser

Hierarchical tree view of the OPC UA address space with real-time search, live value polling, and inline write capability — directly in the RuntimeViewer.

📊 Variable Statistics

Enable per-variable statistics to automatically track min, max, average, and count as live sub-variables.

💾 Backup & Restore

Automatic and scheduled project snapshots with retention management. One-click restore creates a safety backup before reverting, so you never lose work.

🔐 Security

PBKDF2-SHA256 password hashing, user groups with granular access levels, idle auto-logoff, password expiry, project-level password protection, and strong password policy enforcement.

🌍 Localization

Full multi-language support (EN, DE, IT, FR, JA, ZH) for the editor help system and runtime string tables.

📡 REST API

Every server capability is accessible via a built-in REST API — read/write variables, browse tags, query alarms, manage recipes, pull historical data, and monitor diagnostics.

🔐 Certificate Management

View, generate, and manage OPC UA PKI certificates. Register with a GDS, submit CSRs, pull signed certificates, and accept or reject certificates — all from a dedicated editor panel.

☁️ Cloud Bridge & Relay

Extend your on-premises HMI to the cloud with CloudBridge and CloudRelay services for remote monitoring and control.

Architecture Overview

Server

OPC UA server, alarm engine, notification service, REST API, driver host. Ports 14840 (OPC UA), 14841 (diagnostics).

ServerEditorWeb

Blazor Server app for project editing — screens, variables, scripts, settings. Port 8080.

RuntimeViewer

Blazor WebAssembly runtime UI with alarm list, tag browser, diagnostics panel. Port 8088.

SharedModels

Common project model, node definitions, and configuration types shared across all components.

Drivers

13 industrial protocol drivers with a common Drivers.Abstractions interface.

Docker All-in-One

Single container image bundles Server + Editor + Viewer + PostgreSQL + Ollama for zero-config deployment.

🐳 Docker Quick Start

The fastest way to try HMI Solution is the all-in-one Docker image. It bundles the OPC UA server, web editor, runtime viewer, PostgreSQL, and Ollama into a single container.

Pull & Run (All-in-One)

# Pull the all-in-one image
docker pull ghcr.io/clodalone/hmi-allinone:latest

# Run with persistent volumes
docker run -d --name hmi \
  -p 14840:14840 \
  -p 14841:14841 \
  -p 8080:8080 \
  -p 8081:8081 \
  -p 8088:8088 \
  -p 5432:5432 \
  -p 11434:11434 \
  -v hmi-data:/data \
  -v hmi-pgdata:/var/lib/postgresql/data \
  hmi-allinone:latest

Individual Images

You can also run each component separately:

ImageDescriptionPorts
ghcr.io/clodalone/hmi-server OPC UA Server + REST API + Alarm Engine 14840, 14841
ghcr.io/clodalone/hmi-editor Blazor Web Editor 8080, 8081
ghcr.io/clodalone/hmi-viewer Runtime Viewer (Blazor WASM) 8088

Build from Source

# Clone the repository
git clone https://github.com/ClodAlone/HMISolution.git
cd HMISolution

# Build the all-in-one image
dotnet build Server/Server.csproj -c Release -p:BuildDockerImage=true

# Save & load (optional — for offline transfer)
docker save -o hmi-allinone.tar hmi-allinone:latest
docker load -i hmi-allinone.tar

# Run
docker run -d --name hmi \
  -p 14840:14840 -p 14841:14841 \
  -p 8080:8080 -p 8081:8081 -p 8088:8088 \
  -p 5432:5432 -p 11434:11434 \
  -v hmi-data:/data \
  -v hmi-pgdata:/var/lib/postgresql/data \
  hmi-allinone:latest

📡 REST API

The server exposes a comprehensive REST API on port 14841. Use it to integrate HMI Solution into your own dashboards, mobile apps, or automation pipelines.

Variables

Read, write, and browse all project variables.

Alarms

List active alarms, acknowledge, confirm, shelve/unshelve.

Historical Data

Query time-series data stored in PostgreSQL.

Recipes

Manage recipe sets and apply them to runtime variables.

Server Info

Health checks, diagnostics, and server status.
