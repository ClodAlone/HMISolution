## ❓ Frequently Asked Questions

**Q: Can I start with Community and upgrade later?**  
A: Absolutely! Your project files are 100% compatible. Just activate a license key.

**Q: What happens if I downgrade or cancel?**  
A: You keep all your project files and can continue using Community edition features. Premium features will be disabled.

**Q: Do you offer perpetual licenses?**  
A: Enterprise customers can purchase perpetual licenses with optional annual maintenance.

**Q: Is source code included?**  
A: Community (MIT license - full source), Professional (view/modify), Enterprise (full access + customization rights).

**Q: Can I run AI Core HMI completely offline?**  
A: Yes! Use Ollama for local AI. License validation can be done offline for Enterprise customers.

**Q: What payment methods do you accept?**  
A: Credit card, ACH, wire transfer, purchase orders (Enterprise only).
