		Creating custom Satellite Resource Assemblies for different cultures
		--------------------------------------------------------------------

Please take a look at the Suite\Docs\Localization.doc document to get familiar with localizing Essential Suite dlls.


About BuildSatelliteAssembly.bat
--------------------------------

The BuildSatelliteAssembly.bat file in this folder will give you a sample command line that you can customize to create satellite assemblies for the German(Germany) cultures.


The current SatelliteContractVersion used is 2.0.0.0. So, use this version for the resource dlls that you create. The above batch file specifies this version.
